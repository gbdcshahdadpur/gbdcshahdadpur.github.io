# Government Boys Degree College Shahdadpur - Official Website

Welcome to the official web repository for **Government Boys Degree College Shahdadpur**, located in District Sanghar, Sindh.

🌐 **Live Website:** [https://gbdcshdpr.github.io/](https://gbdcshdpr.github.io/)

---

## 📌 Project Overview

This repository contains the front-end source code for the college web portal. The site is designed to provide students, faculty, and visitors with essential information regarding:

* Intermediate & Associate Degree Programs
* Admissions & SECCAP Help Desk Guidance
* Academic Timetables & Fee Structures
* Campus Facilities & Library Resources
* Event Photo Galleries & Historical Archives

---

## 🛠️ Built With

* **HTML5** - Page structure and semantic layout
* **CSS3** - Custom responsive styling and Flexbox/Grid layouts
* **JavaScript (ES6)** - Interactive mobile navigation and gallery filtering
* **Font Awesome 6** - UI Icons
* **Google Fonts** - *Poppins* and *Playfair Display* typography
